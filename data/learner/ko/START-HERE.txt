합성 실습 자료만 포함하며 실제 회사 데이터가 아닙니다.
작은 학습자 ZIP이며 소스 저장소나 준비된 코드 실행 환경이 아닙니다.
압축을 푼 개인 복사본은 저장소 밖에 보관합니다. 작성한 기록이나 인증정보를 커밋하지 않습니다.
아래 전체 주소를 브라우저에서 엽니다. 가이드 페이지는 이 ZIP 안의 파일이 아닙니다.
준비: https://github.com/junwoojeong100/microsoft-foundry-labs-v1.2/blob/main/docs/ko/setup.md
입문 가이드: https://github.com/junwoojeong100/microsoft-foundry-labs-v1.2/blob/main/docs/ko/paths/a-beginner.md#first-success
GitHub 로그인을 요구하면 저장소 읽기 권한이 있는 계정을 사용합니다. Azure 로그인과는 별개입니다.

1. 워크숍 가이드(이 ZIP에는 없음)의 docs/ko/setup.md를 마치고 session-notes.txt의 설정 카드를 채웁니다. judge/router가 아닌 준비된 gpt-6-sol을 사용합니다.
2. 가이드의 docs/ko/paths/a-beginner.md를 따릅니다. Lab 00-03과 06은 session-notes.txt에 기록합니다.
3. Lab 03에서 instructions-with-policies.txt 전체를 대화창이 아닌 Instructions(지침)에 붙여 넣고 Save(저장)합니다. 실제 저장 내용은 instructions-baseline.txt로 보관하고 버전을 적습니다.
4. dev-questions.txt에서 질문 하나만 복사해 매번 새 대화에 보냅니다. ID나 평가 열은 보내지 않습니다.
5. Lab 05는 준비된 터미널이 기본입니다. Hosted Responses Playground는 담당자 검증 후에만 선택합니다. 한 방식만 사용하고 명령 또는 질문, 실제 출력 전체, 내 검토로 workflow-review.txt를 채웁니다.
6. Lab 07에서 assessment.csv를 assessment-baseline.csv로 저장하고 저장 버전 하나로 6행 모두 평가합니다. session-notes.txt의 Lab 07 A에 버전·파일 경로·판단을 기록합니다. 정답표는 없습니다.
오류·미실행도 6문항 분모에 남깁니다. Candidate는 정당한 변경이 있을 때만 선택하며 baseline을 보존합니다.
선택 Lab 07 Foundry 평가: dev-questions.jsonl(질문만)을 데이터 세트로 올립니다. 정답이나 holdout을 추가하지 않습니다.
7. Lab 09에서 operations-checklist.txt를 채우고, Lab 11에서 새 Azure 호출 없이 이 파일들을 인계합니다.
기본 경로: Lab 03과 06에서 policies/의 원래 금액·적용 기간·인용 ID를 확인합니다.
선택 전용: instructions.txt는 기능을 사용할 수 있을 때 별도로 선택한 File Search agent에 사용합니다.
